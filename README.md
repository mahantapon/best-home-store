# คลังสินค้า best home

เว็บสั่งของ/เบิกของจากคลังออฟฟิศ (Office ตลิ่งชัน) แบบแคตตาล็อก ใช้บนมือถือได้ ไม่ต้องติดตั้งแอป ไม่ต้องมีบัญชี

**ลิงก์:** https://mahantapon.github.io/plumbing-stock/

## ใครใช้ทำอะไร

| บทบาท | ทำอะไรได้ |
|---|---|
| **โฟร์แมน / หน้างาน** | เลือกหมวดวัสดุ → ใส่ตะกร้า → ส่งใบเบิก (ระบุไซต์งาน + วันที่ต้องการใช้) → ติดตามสถานะ / สั่งซ้ำ / ยกเลิกใบที่ยังรอจัด |
| **ออฟฟิศ / จัดซื้อ** | เปิดใบเบิกรอจัด → ใส่จำนวนที่จ่ายจริง → ยืนยันจ่ายของ (สต็อกตัดตอนนี้) · หน้า “ต้องสั่งซื้อ” รวมของที่น้อย/ไม่พอจ่าย + ปุ่มคัดลอกรายการไปส่ง LINE · รับของเข้า · ปรับยอดนับจริง · เพิ่มสินค้า · ประวัติสต็อก |

เลือกบทบาทครั้งแรกที่เปิดเว็บ (เปลี่ยนได้ที่การ์ดชื่อมุมซ้ายล่าง / ปุ่ม “ฉัน”) — เป็นแค่การจัดเมนูให้ใช้ง่าย ไม่ใช่สิทธิ์ความปลอดภัย

สถานะใบเบิก: **รอจัด** → **จ่ายครบ** / **จ่ายบางส่วน** / **ยกเลิก** · ใบที่รอจัดยังไม่ตัดสต็อก แต่ถูกนับใน “ติดใบเบิก” และ “ต้องสั่งซื้อ”

## หมวดวัสดุ

ตั้งใน `config.js` → `DEPARTMENTS` (ชื่อ คำอธิบาย สี ไอคอน) — ตอนนี้มี 8 หมวด: ประปา, ไฟฟ้า, สีและเคมีภัณฑ์, ปูนและวัสดุก่อ, เหล็กและโครงสร้าง, ไม้ ประตู หน้าต่าง, ฮาร์ดแวร์ น็อต สกรู, อุปกรณ์ไซต์งาน
มีของแล้วเฉพาะ **ประปา** (42 รายการ จากแท็บ "ประปา สโตร์ ตลิ่งชัน" ของชีต *วัสดุ* พร้อมรูปจริง `images/P01..P42.jpg`) — หมวดอื่นขึ้น "เร็ว ๆ นี้" จนกว่าจะเพิ่มสินค้า (ออฟฟิศกด “เพิ่มสินค้า” ในเว็บ หรือเพิ่มแถวในแท็บ คลัง ใส่คอลัมน์ "หมวดวัสดุ" ให้ตรงชื่อ; ช่องว่าง = ประปา)

ฟอนต์: LINE Seed Sans TH (SIL OFL 1.1) ใน `fonts/`

## ที่เก็บข้อมูลจริง (เชื่อมแล้ว 26 พ.ย. 2569)

- Google Sheet **คลังประปา (ระบบ)** — https://docs.google.com/spreadsheets/d/1il97YFZOG9GbFYqbGHDO_esZ3BQJDZXks6PCSQVahn0/edit
  - แท็บ **คลัง** = ยอดคงเหลือ · **ใบเบิก** = ใบสั่งของจากหน้างาน · **ประวัติ** = ทุกการตัดสต็อก/รับเข้า/ปรับยอด
- Apps Script โปรเจกต์ **คลังประปา API** (ผูกกับชีตนี้) deploy เป็นเว็บแอป (เวอร์ชัน 2): ทำงานในฐานะเจ้าของชีต, เข้าถึงได้ทุกคน
- ยังไม่ได้ตั้ง `TEAM_PIN` — ใครมีลิงก์เว็บก็กดเบิกได้ ถ้าจะตั้ง ดูข้อ 3 ด้านล่าง (ไม่ต้อง deploy ใหม่)

## เชื่อม Google Sheet (ทำครั้งเดียว ~3 นาที)

ถ้ายังไม่เชื่อม เว็บจะขึ้น **โหมดทดลอง** — ข้อมูลอยู่ในเครื่องนั้นเครื่องเดียว คนอื่นไม่เห็น

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `คลังประปา (ระบบ)`
2. เมนู **ส่วนขยาย → Apps Script** ลบโค้ดเดิม แล้ววางทั้งไฟล์ [`apps-script/Code.gs`](apps-script/Code.gs) → กดบันทึก
3. (แนะนำ) ตั้งรหัสทีม: ไอคอนเฟือง **การตั้งค่าโปรเจกต์ → คุณสมบัติสคริปต์ → เพิ่ม** ชื่อ `TEAM_PIN` ค่าเช่น `2580`
4. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → ประเภท: เว็บแอป**
   - เรียกใช้ในฐานะ: **ฉัน**
   - ผู้ที่มีสิทธิ์เข้าถึง: **ทุกคน**
   - กด ทำให้ใช้งานได้ → อนุญาตสิทธิ์ → คัดลอก **URL ที่ลงท้าย `/exec`**
5. เอา URL ไปใส่ใน [`config.js`](config.js) ที่ `API_URL: '...'` แล้ว commit (หรือส่งให้ Claude ใส่ให้)

ครั้งแรกที่เว็บเรียก ระบบจะสร้างแท็บ **คลัง** (ยอดคงเหลือ 42 รายการ) และ **ประวัติ** ให้เอง

- แก้ชื่อ/หน่วย/จุดเตือนในแท็บ "คลัง" ได้ตรง ๆ แต่ **อย่าแก้คอลัมน์รหัส** และอย่าลบแถวในแท็บ "ประวัติ"
- ถ้าแก้ `Code.gs` ภายหลัง ต้อง **ทำให้ใช้งานได้ → จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** (URL เดิม)
- ถ้าตั้ง `TEAM_PIN` ทุกเครื่องต้องใส่รหัสครั้งแรกที่ ⚙️ ตั้งค่า (จำไว้ในเครื่อง)

## โครงสร้าง

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` `styles.css` `app.js` | หน้าเว็บ (ไม่มี build step) |
| `config.js` | ลิงก์ Apps Script, ชื่อคลัง, รายชื่อไซต์ที่แนะนำ |
| `data/seed.json` | ยอดตั้งต้นจากชีต → `node tools/build-seed.mjs` สร้าง `data/seed.js` และฝังใน `Code.gs` |
| `apps-script/Code.gs` | หลังบ้านบน Google Sheet (ล็อกกันกดพร้อมกัน, กันเบิกเกินยอด) |

ทดสอบในเครื่อง: `python3 -m http.server 5178` แล้วเปิด http://localhost:5178
